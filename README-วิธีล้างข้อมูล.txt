วิธีใช้ชุดกู้โปรแกรมและล้างประวัติบิลทดสอบ

1. วางไฟล์ desktop/tax-invoice/tax_invoice_app.html ทับไฟล์ปัจจุบัน
   ไฟล์นี้เป็นเวอร์ชันก่อนหน้าที่เปิดโปรแกรมได้

2. วางไฟล์ clear_tax_invoice_history_once.html ไว้ที่โฟลเดอร์หลัก stock-alert
   ระดับเดียวกับ index.html

3. เปิดระบบผ่าน Start CMS ให้ URL เป็น 127.0.0.1:8765

4. เปิด URL:
   http://127.0.0.1:8765/clear_tax_invoice_history_once.html

5. ติ๊กยืนยัน พิมพ์ "ล้างข้อมูลทดสอบ" แล้วกดล้าง
   - ค่าเริ่มต้นลบ local invoices และ Firestore taxInvoices
   - หากต้องการล้างคำขอพนักงานทดสอบด้วย ให้ติ๊ก "ล้างคำขอจากพนักงานด้วย"

6. เมื่อสำเร็จ ปิดหน้าล้างข้อมูล แล้วเปิดโปรแกรมออกใบกำกับภาษีใหม่

ไม่ลบ:
- products
- customers
- Template
- การตั้งค่าเลขบิล
