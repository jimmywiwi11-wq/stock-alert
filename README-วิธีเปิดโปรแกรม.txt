วิธีใช้

1. แตกไฟล์ ZIP
2. นำไฟล์ .bat ทั้งสองไฟล์ไปวางในโฟลเดอร์หลัก stock-alert
   ตำแหน่งเดียวกับ index.html และ Start-ChokAnan-CMS-Server.ps1

3. ต่อไปให้ดับเบิลคลิก:
   เปิดโปรแกรมโชคอนันต์.bat

หรือถ้าต้องการเปิดหน้าใบกำกับภาษีโดยตรง:
   เปิดโปรแกรมออกใบกำกับภาษี.bat

ห้ามดับเบิลคลิก index.html โดยตรง
เพราะจะเปิดเป็น File D:/... และระบบ iframe/Firebase อาจไม่ทำงาน
